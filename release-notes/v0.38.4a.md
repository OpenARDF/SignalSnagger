# SignalSnagger 0.38.4a direct-audio test candidate

This test candidate isolates the remaining weak-signal sensitivity regression
after hardware comparison showed that disabling the band-pass filter improves
sensitivity but does not restore the original 0.38 baseline.

## Experimental listening path

- Make audio-filter `OFF` a direct 48 ksample/s listening path so every ADC
  sample reaches the DAC without the four-to-one decimator or fixed-point
  band-pass stages.
- Retain signed, centered, saturating gain and bounded 12-bit-to-10-bit DAC
  conversion instead of restoring the baseline's unsigned wrap behavior.
- Continue the 12 ksample/s analysis path in parallel for signal detection and
  retain the existing filtered modes for immediate on-device A/B comparison.
- Advance beeps, ticks, and RF-gain cues from the shared 12 kHz control timeline
  so their pitch and duration remain consistent in direct and filtered modes.

## Intended hardware comparison

At fixed frequency, RF gain, audio gain, CW offset, and signal-generator level,
compare filter `OFF` against the 800 Hz filter. Record whether direct mode
restores minimum discernible signal, removes near-threshold artifacts, or
changes the debugger-visible dropped-frame counter.

## Programmer-side hardware validation

On 2026-11-01, this exact candidate was programmed into the connected
AVR128DA48 through Atmel-ICE `J41800053674` using a device-supported isolated
flash erase. The device signature was `1E9708`, and target voltage measured
3.31 V before programming.

- Firmware HEX SHA-256:
  `859b4480eae62682ef017d4dff7029ce8bd367d1356cc0cafe3b51eb4c985968`
- Padded 128 KiB candidate and independent flash-readback SHA-256:
  `ef8e065ef9b4ceca7484a52546ccad83b3376905aca76d5f473e3da57fdbdb1c`
- Pymcuprog write verification passed.
- EEPROM, fuses, lock bits, and user row were byte-identical before and after
  programming.
- The target reset into normal execution and measured 3.30 V afterward.

The operator subsequently reported that the candidate works much better and
that filter `OFF` restores almost all of the original baseline sensitivity.
The About row displayed only `0.38.4` because its historical `Ver:` prefix made
the suffixed version one character wider than the display; the source has been
shortened to `V:` for the next candidate. Confirmation of the remaining boot,
controls, LEDs, audio-cue, and power-management checks remains pending.
