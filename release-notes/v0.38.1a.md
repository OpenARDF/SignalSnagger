# SignalSnagger 0.38.1a test firmware

This is a hardware-test candidate based on the recovered, deployed 0.38
firmware. It is not a published release.

## User-visible changes

- Preserve the released headphone-removal 60-second countdown and power-down
  behavior while making the shared countdown access interrupt-safe.
- Keep VFO and memory tuning within the supported 3.5–4.0 MHz range.
- Fall back safely to VFO mode when no programmed memory channel exists.

## Stability and reliability

- Prevent torn foreground/interrupt access to multi-byte counters and events.
- Prevent the Goertzel analysis block from being overwritten while it is being
  evaluated at the three released detector frequencies.
- Bound I2C, ADC, and EEPROM hardware waits so a failed peripheral cannot hang
  the foreground indefinitely.
- Correct EEPROM field-width writes, one-past-end array reads, invalid enum and
  channel indices, and string termination on corrupted EEPROM data.
- Make display reset timing blocking and deterministic.
- Harden circular buffers against ownership, initialization, framing, and
  destination-capacity errors.
- Validate time strings and calendar dates before conversion.

## Protected receiver behavior

The experimentally established Si5351 quadrature implementation and register
sequence are unchanged from deployed firmware 0.38.

## Hardware validation

Completed programmer-side validation on the connected AVR128DA48 receiver with
Atmel-ICE J41800053674:

- device signature `1E9708` identified before writing;
- pre-write flash, EEPROM, fuses, lock bits, and user row were backed up;
- only flash was erased using the device-supported isolated flash erase;
- pymcuprog write verification passed;
- full 128 KiB flash readback matched the padded candidate image (SHA-256
  `a45efa37a11cf7000982ee7509e2fa9deb90099aca97e9ae488df7e0a9e40a55`);
- EEPROM, fuses, and user row were byte-identical before and after programming;
- the target reset into normal execution at 3.29 V.

The following operator-observed checks remain pending:

- displayed version is 0.38.1a;
- no false 32 kHz clock error;
- startup and signal/noise LED behavior;
- tuning, sensitivity, RF gain, and audio gain;
- Si5351 quadrature output behavior;
- headphone removal shows the full 60-second countdown and powers down;
- reconnecting headphones recovers as designed.
