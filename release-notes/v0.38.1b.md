# SignalSnagger 0.38.1b test firmware

This is the next hardware-test candidate based on the recovered, deployed 0.38
firmware. It includes all 0.38.1a changes plus an EEPROM power-loss correction.
It is not a published release.

## User-visible changes

- Preserve the released headphone-removal 60-second countdown and power-down
  behavior while making the shared countdown access interrupt-safe.
- Keep VFO and memory tuning within the supported 3.5–4.0 MHz range.
- Fall back safely to VFO mode when no programmed memory channel exists.

## Stability and reliability

- Wait for each EEPROM operation to complete, including the last setting saved
  immediately before power is removed.
- Prevent torn foreground/interrupt access to multi-byte counters and events.
- Prevent the Goertzel analysis block from being overwritten during three-tone
  analysis.
- Bound I2C, ADC, and EEPROM hardware waits.
- Correct EEPROM write widths, array bounds, corrupted enum/channel values, and
  string termination.
- Reject undefined RSSI logarithms before they can become arbitrary unsigned
  values and affect LED indications.
- Keep diagnostic sine generation within its sample table and frame LED text
  messages so the display queue cannot stall.
- Harden display reset timing, circular buffers, frequency bounds, and date/time
  parsing.

## Protected receiver behavior

The experimentally established Si5351 quadrature implementation and register
sequence are unchanged from deployed firmware 0.38.

## Hardware validation

On 2026-10-19, this exact image was programmed into the connected AVR128DA48
through Atmel-ICE J41800053674 using an isolated flash erase. Independent
128 KiB flash readback matched the padded candidate byte-for-byte. EEPROM,
fuses, and user row were also read before and after programming and remained
byte-identical. The device signature was `1E9708`, and target voltage after
reset was 3.30 V.

Operator-observed functional checks remain pending for this exact image,
including the display version, 32 kHz startup status, startup and signal LED
behavior, receiver audio/tuning/gain, quadrature reception, the full 60-second
headphone-removal countdown and power-down, and recovery after reconnecting
headphones.
