# SignalSnagger 0.38.1e test firmware

This test candidate adjusts the receiver's front-end gain scale. It is not a
published release.

## User-visible change

- Displayed RF gain 0 now uses the former RF gain 3 PWM value.
- Displayed RF gain 10 retains its existing maximum-gain endpoint.
- Displayed settings 1 through 9 use provisional linear interpolation between
  those endpoints until measured nonlinear calibration data is available.

## Protected receiver behavior

The change reuses the existing RF gain PWM table and `setPWM` path. Tuning,
audio gain, EEPROM behavior, and the experimentally established Si5351
quadrature implementation remain unchanged.

## Hardware validation

On 2026-10-19, this exact image from commit `9fe4f30` was programmed into the
connected AVR128DA48 through Atmel-ICE J41800053674 using an isolated flash
erase. The device signature was `1E9708`. Programmer verification passed, and
an independent 128 KiB flash readback matched the padded candidate
byte-for-byte with SHA-256
`ed2f188d5d6b79b2a3dda5e3f6f218d217a6fcec5721fcaf3498c693cbfeda14`.
EEPROM, fuses, user row, and lock bytes were read before and after programming
and remained byte-identical. The target reset into normal execution at 3.30 V.

Operator-visible boot/version confirmation and focused testing of the revised
gain steps remain pending.
