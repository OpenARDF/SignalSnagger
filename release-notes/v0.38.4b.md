# SignalSnagger 0.38.4b direct-audio timing test candidate

This candidate retains the successful `0.38.4a` direct listening math while
reducing work in the high-priority 48 ksample/s ADC interrupt.

## Experimental changes

- Move beep, tick, RF-gain cue, and audio-control sequencing back to the
  lower-priority 12 ksample/s processing interrupt.
- Transfer gain, feedthrough, and injected-tone state through two control slots;
  the lower-priority ISR writes the inactive slot and publishes it with one
  byte-sized index update so the ADC ISR cannot observe a torn frame.
- Record the maximum measured ADC ISR duration and timer-wrap deadline misses.
  The About screen shows `A<m> T<t>`, where `A` is the saturated deadline-miss
  count and `T` is the maximum measured timer ticks, each capped at 999 for the
  display.
- Shorten the About version prefix from `Ver:` to `V:` so suffixed test versions
  fit the ten-column row.

## Preserved behavior

- Filter `OFF` remains the direct 48 ksample/s listening path.
- Filtered modes retain the existing 12 ksample/s decimation and fixed-point
  band-pass processing for immediate A/B comparison.
- Signed, centered, saturating gain and bounded DAC conversion are unchanged
  from `0.38.4a`.

## Programmer-side hardware validation

On 2026-11-01, this exact candidate was programmed into the connected
AVR128DA48 through Atmel-ICE `J41800053674` using a device-supported isolated
flash erase. The device signature was `1E9708`, and target voltage measured
3.29 V before programming.

- Firmware HEX SHA-256:
  `56b886af6cfe52b6de3a49b2291f0d6b5621d3ff3d6bf1ba40db9cb62d2d23b3`
- Padded 128 KiB candidate and independent flash-readback SHA-256:
  `95a49bd092000c2394b8a3f3cb3cf99c4e3b4b18b3284641eb7a1e1e23cfd155`
- Pymcuprog write verification passed.
- EEPROM, fuses, lock bits, and user row were byte-identical before and after
  programming.
- The target reset into normal execution and measured 3.30 V afterward.

The operator subsequently reported that `0.38.4b` sensitivity with filter
`OFF` was roughly the same as `0.38.4a`, and the complete `b` suffix was
visible. The About-screen deadline row was not visible because About inherited
the Main Menu's three-line LCD mode; the counters remained active in RAM.
Confirmation of controls, LEDs, audio cues, and power-management behavior
remains pending.
