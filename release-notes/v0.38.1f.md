# SignalSnagger 0.38.1f test firmware

This cumulative test candidate combines the provisional front-end gain remap
from 0.38.1e with the receiver tuning-acceptance fix. It is not a published
release.

## User-visible changes

- Accepting a newly selected memory channel or VFO frequency no longer clears
  and redraws the complete display.
- The side-button acceptance action no longer changes the cardioid RF path or
  interrupts receiver audio while frequency editing is active.
- Displayed RF gain 0 uses the former RF gain 3 PWM value, displayed RF gain 10
  retains its prior endpoint, and settings 1 through 9 use provisional linear
  interpolation pending measured calibration.

## Protected receiver behavior

Tuning acceptance persists only the active frequency, frequency mode, and
memory channel. The switch state remains visible to the existing UI handling,
while AVR port control suppresses cardioid selection until the accepting side
button is released. EEPROM, fuses, lock bytes, and the user row are not part of
the planned flash write.

## Validation

Build, programming, independent readback, and operator-visible functional
testing are pending.
